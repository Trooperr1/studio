# JAFF STUDIO - Premium Digital Solutions

A modern, premium website showcasing digital services including web development, AI solutions, POS systems, and social media management. Features a stunning 3D animated background with black and white branding.

## Features

- **3D Animated Background**: Immersive Three.js particle system and geometric shapes
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Premium Black & White Theme**: Elegant, professional color scheme
- **Multiple Pages**:
  - Home - Hero section with service overview and statistics
  - Services - Detailed breakdown of all services offered
  - About - Company story, mission, values, and team
  - Contact - Contact form and information
- **Interactive Elements**:
  - Smooth scrolling navigation
  - Animated service cards
  - Counter animations for statistics
  - Mobile-friendly hamburger menu
  - Form validation

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations
- **JavaScript (ES6+)** - Interactive functionality
- **Three.js** - 3D graphics and animations
- **Google Fonts (Inter)** - Premium typography

- Reduced particle count on mobile devices

- Optimized 3D rendering with requestAnimationFrame
- Lazy loading for smooth scrolling

## Customization

### Colors
Edit CSS variables in `assets/css/style.css`:
```css
:root {
    --primary-black: #0a0a0a;
    --secondary-black: #1a1a1a;
    --light-gray: #f5f5f5;
    --medium-gray: #999;
    --white: #ffffff;
}
```

### 3D Animation
Modify particle count and animation speed in `assets/js/3d-background.js`
